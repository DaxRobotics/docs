ROS2 二次开发接口

Dax x7 Pro / X7-EDU 旗舰版原生基于 ROS2 构建，支持通过 Topics、Services、Actions 和 MoveIt2 / Nav2 生态进行二次开发。本页整理 PDF 说明书中的 ROS2 通信参数、核心话题、控制器和服务接口。

通信拓扑配置​

机器人底盘拥有固定静态 IP 节点，集群通信默认使用 Eclipse CycloneDDS 作为通信中间件。开发者在上位机或实验室工作站中，可将以下环境变量写入 ~/.bashrc 加入机器人的分布式 DDS 通信域：

export ROS_DOMAIN_ID=20
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI=/home/nvidia/cyclonedds.xml

底层通信节点默认网卡接口名称为 eth0，最大消息报文大小为 65500B，接收缓冲区大小为 10MB。在多机器人联合调度或强电磁干扰环境下发生点云丢包时，可根据交付配置调整 cyclonedds.xml，并按需启用共享内存通信。

核心 Topic 通信矩阵​

底盘控制状态反馈​

项目内容
话题/base_control_status
类型robot_interfaces/msg/RobotBaseStatus
状态码0=INIT、1=ACTIVATE、2=ERROR、3=SHUTDOWN、4=EMERGENCY

底盘速度控制接口​

通道话题类型说明
高优先级遥控接口/joy_velgeometry_msgs/msg/Twist手柄遥控，优先级高
低优先级导航接口/cmd_velgeometry_msgs/msg/Twist导航或开发程序下发速度
底盘实际执行接口/twist_mux/cmd_velgeometry_msgs/msg/Twist速度多路复用后的最终执行通道

底盘遵循标准差速与全向运动学控制，可通过三维线速度 linear.x、linear.y 和绕 Z 轴角速度 angular.z 实现任意维度平移与旋转。

里程计与惯导​

数据话题类型
原始里程计/omnidirectional_controller/odomnav_msgs/msg/Odometry
融合后里程计/odomnav_msgs/msg/Odometry
IMU 数据/imu/data以交付接口为准

融合里程计结合底盘 IMU 高频数据进行卡尔曼滤波，为移动操作算法提供位姿底座。

避障相机点云数据​

旗舰版搭载三路底盘深度相机，分别发布左侧、前向和右侧感知数据：

  • 左侧：/left_depth
  • 前向：/front_depth
  • 右侧：/right_depth

每路相机包含以下标准主题命名空间：

数据后缀
原始图像.../color/image_raw
压缩图像.../color/image_raw/compressed
深度相机元数据.../depth/camera_info
深度图像.../depth/image_raw
三维密集点云.../depth/points
滤波点云.../depth/points/filtered_raw

滤波点云已在底层滤除大面积地面噪点，可直接输入三维激光/视觉障碍物局部规划器。

全身关节状态​

项目内容
话题/joint_states
类型sensor_msgs/msg/JointState
频率最高 200Hz
内容全身 26 个自由度关节的位置 position、速度 velocity 和力矩反馈 effort

FollowJointTrajectory 控制器​

Dax x7 全身复杂运动链基于 ROS2 标准 FollowJointTrajectory 控制器驱动。使用 MoveIt2 或自定义轨迹控制时，可对接以下 Action 服务。

控制对象Action 服务Joint Names
头部 2 DoF/head_controller/follow_joint_trajectoryhead_joint0, head_joint1
左臂 7 DoF/left_arm_controller/follow_joint_trajectoryleft_arm_joint0 至 left_arm_joint6
右臂 7 DoF/right_arm_controller/follow_joint_trajectoryright_arm_joint0 至 right_arm_joint6
躯干旋转 1 DoF/waist_rotation_controller/follow_joint_trajectorywaist_joint3
躯干升降 3 DoF/waist_controller/follow_joint_trajectorywaist_joint0, waist_joint1, waist_joint2

核心 Service / Action 接口​

接口类型说明
/power_offstd_srvs/srv/SetBool传入 data=true 时执行系统安全同步并关闭总电源输出，重新开机需物理按下软开关
/emergency_controlstd_srvs/srv/SetBool整机急停控制；底盘无动力松轴，14 个手臂关节进入位置锁死保持状态
/set_slamrobot_interfaces/srv/SetSlam控制建图和定位线程，支持 build、save、switch、reloc
/charging_srvrobot_interfaces/srv/Charging自动回充控制，支持 dock 和 undock
/charging_statusTopic回充状态反馈，可解析导航前哨点、精细对准和成功通电等状态
/navigate_to_poserobot_interfaces/action/NavigateToPose指点导航高级任务，接收 geometry_msgs/PoseStamped pose 和 behavior_tree

/set_slam 的 cmd 字段含义：

cmd含义
build启动未知环境建图线程
save保存当前地图到 mapdir，生成 filename.pbstream 与 filename.pgm
switch加载已有静态地图，并通过 initial_pose 控制机器人重定位
reloc在已知地图中触发全局自主重定位

/charging_srv 的 cmd 字段含义：

cmd含义
dock一键自主对接充电桩
undock自动脱离充电桩并倒车至安全区域

/navigate_to_pose 执行过程中会反馈当前坐标 current_pose、剩余距离 distance_remaining 和当前移动速度，导航成功返回状态码 SUCCEEDED=0。

Python 开发示例​

下面示例基于 rclpy 展示如何发布底盘速度、下发左臂轨迹，并向导航 Action 发送目标点。示例中的接口来自说明书，实际工程中请结合交付功能包和消息定义调整 import 路径。

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from rclpy.action import ActionClient
from geometry_msgs.msg import Twist, PoseStamped
from trajectory_msgs.msg import JointTrajectory, JointTrajectoryPoint
from robot_interfaces.action import NavigateToPose


class DaxX7EduDeveloperDemo(Node):
    def __init__(self):
        super().__init__('dax_x7_edu_dev_demo')
        self.cmd_vel_pub = self.create_publisher(Twist, '/cmd_vel', 10)
        self.left_arm_pub = self.create_publisher(
            JointTrajectory,
            '/left_arm_controller/joint_trajectory',
            10,
        )
        self.nav_client = ActionClient(self, NavigateToPose, '/navigate_to_pose')
        self.get_logger().info('Dax_X7 EDU 旗舰版二次开发演示节点已启动')

    def move_base_example(self, linear_x, angular_z):
        msg = Twist()
        msg.linear.x = float(linear_x)
        msg.angular.z = float(angular_z)
        self.cmd_vel_pub.publish(msg)

    def command_left_arm_wave(self):
        traj_msg = JointTrajectory()
        traj_msg.joint_names = [f'left_arm_joint{i}' for i in range(7)]
        point = JointTrajectoryPoint()
        point.positions = [0.0, 0.2, 0.0, -0.5, 0.0, 0.1, 0.0]
        point.time_from_start.sec = 3
        traj_msg.points.append(point)
        self.left_arm_pub.publish(traj_msg)

    def send_navigation_goal(self, map_x, map_y, theta_z=0.0):
        if not self.nav_client.wait_for_server(timeout_sec=5.0):
            self.get_logger().error('未找到导航目标点 Action 服务器，请确认 Nav2 模块已启动')
            return
        goal_msg = NavigateToPose.Goal()
        goal_msg.pose.header.frame_id = 'map'
        goal_msg.pose.pose.position.x = map_x
        goal_msg.pose.pose.position.y = map_y
        goal_msg.pose.pose.orientation.z = theta_z
        goal_msg.pose.pose.orientation.w = 1.0
        self.nav_client.send_goal_async(goal_msg)


def main(args=None):
    rclpy.init(args=args)
    node = DaxX7EduDeveloperDemo()
    node.command_left_arm_wave()
    node.move_base_example(0.2, 0.0)
    node.send_navigation_goal(5.5, 2.3)
    rclpy.spin(node)
    rclpy.shutdown()

开发安全要求​

  • 运动控制前先确认急停可用，并让现场人员观察机器人。
  • 底盘速度、双臂轨迹和导航任务都应设置速度限制、边界条件和超时。
  • 使用 /emergency_control 或物理急停前，应理解底盘松轴和手臂位置锁死的行为差异。
  • 地图保存、地图切换和自动回充任务应先在低速、空旷环境验证。
