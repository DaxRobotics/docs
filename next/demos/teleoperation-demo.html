遥控 Demo

遥控 Demo 用于验证控制终端、网络延迟、运动指令和安全停止流程。

适用产品​

  • Dax x7
  • 骐骥 T1000

运行步骤​

  1. 确认场地安全，急停可用。
  2. 启动机器人并连接开发机。
  3. 打开遥控 Demo。
  4. 使用低速模式验证前进、后退、转向或姿态控制。
  5. 触发停止命令，确认机器人停止。
# TODO: 替换为正式命令
python demos/teleoperation_demo.py --config config/robot.yaml --speed low

验证​

  • 控制延迟在可接受范围内。
  • 机器人响应方向与控制输入一致。
  • 停止命令和急停均有效。
  • 日志记录了遥控输入和机器人状态。
